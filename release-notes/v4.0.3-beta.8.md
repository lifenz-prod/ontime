## New
- **Saved timecode setups:** in Settings → Timecode, save the current timer list under a name with **Save as setup**, and bring it back later with **Load**. Saved setups are shared by every project, so a show's timers can be set up once and used anywhere. Saving under an existing name updates that setup. After loading, press Save to use those timers in the project

## Fixed
- **Timecode timers follow the project:** each project keeps its own timecode settings, but switching project used to leave the previous project's timers running until Ontime was restarted. Loading a project now switches to its timers, input and on/off setting straight away
