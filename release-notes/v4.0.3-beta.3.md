## New
- **Timecode on any Dante channel:** on macOS, Settings → Timecode can read timecode from any channel of a sound card, such as channel 9 of a 16 channel Dante Virtual Soundcard. Before, only channels 1 and 2 worked. Inputs are listed with their channel count, and Channel is now a list of that input's channels. The reader only runs while timecode is turned on, so a Mac that isn't using it does no timecode work. The first time you turn it on, macOS asks to allow Ontime to use the microphone: allow it, as that is how it hears the timecode input
